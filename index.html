Selected work

Six projects, from a rehab app to a water-quality probe.

  1. HemoPhysio

    Flutter · Dart · FastAPI · Firebase · ESP32-S3

    A physiotherapy and rehab app for people with haemophilia. The Flutter app runs on a FastAPI backend with Firebase sign-in and storage.

    On the hardware side, an ESP32-S3 reads an MPU motion sensor and BioAmp muscle signals to track how each exercise is going.

  2. Fieldwise

    HTML · CSS · JavaScript

    A farm and irrigation simulator. Pick a crop and a weather scenario, then run thirty days.

    It schedules irrigation and tracks soil moisture and crop vitality day by day, using simplified simulation rules.

  3. SkillConnect

    Java · JSP · Servlets · JDBC · MySQL · Tomcat

    A full-stack platform that connects skilled professionals with the people who need them.

    Built on MVC, with login, session management, database integration and full create, read, update and delete.

  4. Pura Air

    ESP32 · MQTT · IoT

    Real-time indoor air quality monitoring, with several sensors feeding one ESP32 and publishing over MQTT.

    The architecture leaves room for AI-based prediction and cloud connectivity next.

  5. Pura Aqua

    ESP32 · Embedded systems

    An affordable water-quality probe that reads pH, TDS, turbidity and temperature.

    Embedded logic assesses each sample in real time and recommends how to purify it.

  6. WelfareWatch

    SQL · Data analytics · Dashboards

    Interactive dashboards that check how welfare schemes are actually being delivered.

    Visual reports compare performance indicators and beneficiary trends across schemes.

Charts are illustrations of what each project measures, not live data.
